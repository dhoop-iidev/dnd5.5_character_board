# Plateau SRD 5.2.1 (règles 2024)

A personal, offline, bilingual (FR/EN) character playboard for the 2024 rules of the System Reference Document 5.2.1: computed values with their breakdown
and SRD page, rule checks that warn without blocking, live hit points, rests, conditions and spell slots.
Installable as a PWA on a tablet; the character stays in the browser and travels as a JSON file.

- `npm run dev` / `npm run build` / `npm run check` / `npm test`
- Data: see `tools/README.md` (the SRD PDFs are not in the repo).
- Rules: the 2024 rules (SRD 5.2.1) only — `src/__tests__/no-35.test.ts` fails on 3.5 or 2014 vocabulary.
